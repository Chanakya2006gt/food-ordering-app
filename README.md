# BiteFlow - Online Food Ordering App

A responsive food ordering platform with dietary filtering, restaurant discovery, instant payments, and GPS tracking.

## Agile Scrum Implementation

### Sprint 1: Core User & Menu Browsing
- **Issue #1**: User Authentication & Profiles (Customer / Corporate accounts)
- **Issue #2**: Restaurant & Menu Browsing (Dietary tags, search, and dynamic cards)
- **Deliverables**: `index.html`, `style.css`, `app.js`

### Sprint 2: Checkout & Order Tracking
- **Issue #3**: Cart Management (Item count, subtotal calculation)
- **Issue #4**: Online Payment Gateway Integration (Stripe webhook reconciliation receipt)
- **Issue #5**: Real-Time Order & Delivery Tracking (Live status stepper, GPS simulation)
- **Deliverables**: `tracking.html`

## How to Run Locally
Open `index.html` in any web browser or serve with:
```bash
python3 -m http.server 8000
```
